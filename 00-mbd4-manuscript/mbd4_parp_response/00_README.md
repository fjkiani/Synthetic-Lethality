# MBD4 Deficiency: Triaxis Therapeutic Vulnerability

The MBD4 evidence model contains three independently gated therapeutic axes:

1. **Cytidine analog synthetic lethality** — isogenic knockout, rescue, and in vivo evidence.
2. **ATR/WEE1 checkpoint inhibition** — canonical GDSC2 pharmacology with MSI, TP53, leave-one-out, and lineage stress tests.
3. **Hypermutator-directed immune checkpoint blockade** — CpG>TpG mechanism, a sentinel anti-PD1 responder, and a retrospective metastatic uveal melanoma cohort.

The PARP1 branch is governed separately because MBD4 status does not create a PARP1-high transcriptional state. The 7.41 log1p TPM Q75 value is a dataset-derived exploratory boundary for prospective companion-diagnostic development.
